## Linear Algebra
#### FOUNDATIONAL INTUITION
To formalise intuitive concepts mathematics defines ~={cyan}objects/symbols=~ and ~={cyan}manipulation rules=~.

#### CORE CONCEPTS
**~={purple}VECTORS=~**: Vectors can be defined as any objects/symbols that have a ~={cyan}direction=~ and a ~={cyan}magnitude=~. Vectors follow the following manipulation rules:
- Vector Addition results in vectors.
- Scalar Multiplication of vectors results in vector.

#### KEY CONCEPTS
- *~={purple}Closure=~* : Vector Addition/Scalar Multiplication ∈ Vector Set.
- *[[Vector Space]]* : 
	  Set of Vectors Scaled/Added together form a Vector Space.
	  ~={cyan}Formally=~:
		  Let V be a set of Vectors and R be a field[^1], 
		  Then V is a vector space over R if it is equipped with vector addition and scalar multiplication.
- *[[Linear Equations]]* : 
	  Problems can be formulated as linear equations with linear algebra providing tools to solve these equations.
