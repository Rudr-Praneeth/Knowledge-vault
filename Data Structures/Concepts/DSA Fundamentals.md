## DATA STRUCTURES AND ALGORITHMS
~={cyan}Algorithm=~: An algorithm is a finite, well-defined sequence of computational steps that transforms an input into a correct output, and terminates in finite time for every valid input.
Characteristics of Algorithm:
- Finiteness
- Correctness
- Definiteness
Data structures manage how data is stored and accessed. Algorithms focus on processing this data.
Multiple algorithms can solve **the same problem** while requiring radically different amounts of computational resources hence analysis of algorithms is essential to ensure the most efficient is used to solve a given problem.
