## Introduction
JavaScript is a **high-level, dynamically typed, multi-paradigm programming language** primarily used to implement dynamic and interactive behaviour in applications.
~={purple}***Key Points***=~:
- Not restricted to browsers. 
  Executes outside browsers through environments such as Node.js.

#### ~={purple}***JavaScript vs ECMAScript***=~
These two terms are related but not identical.
- **ECMAScript:** The language specification that defines 
	- Syntax
	- Semantics
	- Built-in objects and behaviour
- **JavaScript:** The programming language implementing the ECMAScript specification along with host-provided capabilities[^1].

#### ~={purple}***JavaScript Characteristics***=~
- **High-level Language**
  Programming Language that abstracts away many low-level hardware operations.
- **Dynamically-typed Language**
  Types are assigned during runtime and variables are not type-bound during the time of declaration.
- **Multi-Paradigm Language**
  Supports multiple programming styles.
	- **Procedural**: Programs are organised around sequence of instructions.
	- **Object-Oriented**: Programs organise data and behaviour using objects and classes.
	- **Functional**: Programs can use functions as building blocks, transform data and minimise side effects.
- **First-class Functions**:
  Functions are treated as first-class values.
  They can be:
	- Assigned to variables.  
	- Passed as arguments.
	- Returned from other functions.
	- Stored in objects and arrays.
- **Single-threaded Execution Model**: 
  JavaScript execution in a main-thread is single-threaded. 
  Browsers and Node.js provide asynchronous facilities and JavaScript can use workers for parallel execution.
- **Interpreted and JIT compiled programming language**: 
  JavaScript is commonly described as an interpreted language, but modern JavaScript engines use more sophisticated execution strategies such as:
	- Parsing   
	- Bytecode generation.    
	- Interpreter execution.    
	- Just-in-time (JIT) compilation and optimization of frequently executed code.


#### ~={purple}***JavaScript Execution Model***=~
JavaScript program requires an execution environment that provides the JavaScript engine and additional capabilities required by the program.
There are two major environments:
- ***Browser Environment***: The browser provides:
	- JavaScript engine.
	- DOM (Document Object Model).
	- BOM (Browser Object Model).
	- Web APIs.
	- Networking and storage capabilities.
	- Timers and event handling.
-  ***Server-side Environment***: NodeJS provides:
	- JavaScript engine (V8).
	- File system APIs.
	- Networking APIs.
	- Process management.
	- Event loop and asynchronous I/O facilities.
A JavaScript engine is software responsible for processing and executing JavaScript code. V8 is the most widely using JavaScript engine. Other engines include JavaScriptCore, SpiderMonkey.
A JavaScript engine generally performs the following operations:
- **Parsing***: Syntax analysis and AST generation
- ***Compilation***: Intermediate representation i.e. AST generation.
- ***Execution***: The engine executes the generated Bytecode instructions. In V8, Ignition is the interpreter that executes bytecode. Frequently executed code can be optimized through JIT compilation using TurboFan which can generate machine code for more efficient execution.
~={cyan}***Synchronous and Asynchronous Execution***=~
**Synchronous Execution**: Instruction execute sequentially where each instruction completes before the next synchronous equation.
**Asynchronous Execution**: Some operations can be initiated without blocking the JavaScript thread while waiting for their completion.
