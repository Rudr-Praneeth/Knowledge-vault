# Data Structures
Python supports several types of data structures. Each data structure operates differently and has its own unique applications. 
The data structures supported by *Python* are as follows:
## [[Lists]]
Choose a list when:
- The collection elements need to be replaced. 
- The collection needs to grow or shrink.
## [[Tuples]]
Choose a tuple when:
- The collection is fixed i.e. whose elements cannot be replaced.
- The collections needs to be structurally modified.
- You need a hashable composite key and all its elements are hashable.
## [[Dictionaries]]
Choose a dictionary when:
- A mapping or association of key-value pairs is to be stored and managed
## [[Sets]]
Choose a set when:
- The collection of non-duplicate elements.
