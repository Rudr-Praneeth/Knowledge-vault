#### Python Enhancement Proposal
A PEP is a document proposing, describing, or documenting changes and standards related to Python.
The official PEP index is: [Python PEP Index](https://peps.python.org/)
Think of PEPs as part of Python's design and governance process.
They can cover different things, including:
- proposed language features
- standards
- processes
- conventions
- documentation of important Python decisions

PEP Is beyond addition of new features it has multiple purposes few of which are:
- PEP 8 is the famous Python **Style Guide for Python Code**.
- **PEP 20** contains the Zen of Python.
- **PEP 484** introduced the specification for type hints.
- **PEP 572** introduced assignment expressions (`:=`).

## Python Hacks
#### FUNCTION: help() 
Python also provides built-in documentation access.
This means you don't always have to leave Python to begin investigating an API.

#### ATTRIBUTE: \_\_doc\_\_
Many Python objects expose documentation through `__doc__`.
This is not a replacement for full official documentation.

#### FUNCTION: dir()
Another useful introspection tool that gives what attributes and methods are available on that object.
Used for quick inspection.

>NOTE:
>	~={purple}dir=~(): Discovery
>	~={purple}help=~(): Quick explanation
