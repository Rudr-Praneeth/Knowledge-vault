## Strings
Strings are ***immutable*** in Python.
A **string** is a Python object representing text. Strings can contain:
- Letters
- Numbers
- Spaces
- Punctuations
- Symbols
- Unicode characters

#### Escape Sequences
An **escape sequence** is a special character representation beginning with `\`.
- New line: `\n`
- Tab Space: `\t`
- Backslash: `\\`
- Single Quote: `\'`
- Double Quote: `\"`

#### String Operations
- ~={purple}STRING CONCATENATION=~ : String concatenation with + requires compatible string operands.
  `STRING + STRING`
- ~={purple}STRING REPETITION=~: Strings can be repeated using \*.
  `STRING * NUMBER`
- ~={purple}STRING LENGTH=~: gives the number of characters in a string.



#### IMPORTANT NOTE
- Triple-quoted strings are particularly useful for multiline text.
